# tanya-sriv.github.io

Portfolio + editorial blog. Terminal-styled home, editorial blog posts.
Built with Jekyll; GitHub Pages builds it automatically.

## Deploy

1. Push to the `main` branch of `Tanya-Sriv.github.io`.
2. Repo -> Settings -> Pages -> "Deploy from a branch: main / root".
3. Site appears at https://tanya-sriv.github.io within a minute or two.

## Write a post

Add a markdown file to `_posts/` named `YYYY-MM-DD-your-title.md` with
front matter (layout: post, title, tags). Push. Done.
