Start writing here

This is the visual editor — it is the page your readers will see. Select text for the formatting bubble, or use the full ribbon above: colors, highlights, alignment, lists, tables you type into, and the ✏ draw tool for hand sketches.

Delete all this and write your post — or hit ⤓ import from Medium to bring an existing story over.

Publishing: publish on GitHub opens a pre-filled new-file page in your repo — review and press Commit; the site rebuilds in ~a minute. Long post? Use download .md and drop the file into _posts/.

⤓ Import from Medium

Open your story on Medium → select all (Ctrl/Cmd A) → copy (Ctrl/Cmd C) → click the box below → paste (Ctrl/Cmd V). Formatting, images and embeds come along; Medium clutter is stripped.
